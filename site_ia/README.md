# Face.IA

Página baseada na interface original preservada no histórico do repositório.

## Arquivos

- `index.html`: cópia do HTML histórico `main.html`.
- `style.css`: folha de estilos histórica.
- `logo2.jpg` e fontes: recursos visuais usados pela interface.

O HTML histórico contém um elemento `<canvas>` vazio. O histórico disponível não contém o script que ativava a câmera ou a rotina de avaliação facial; portanto, esta cópia restaura a estrutura visual original, mas não reproduz esses comportamentos.
